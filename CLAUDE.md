# print-calc — калькулятор себестоимости 3D-печати

Описание и запуск — в `README.md`.

## Цель
Общедоступный бесплатный калькулятор для людей, которые продают 3D-печать. С 10.11.2026 репозиторий публичный, сайт — https://an-gah-v.github.io/print-calc/ (GitHub Pages из ветки main: каждый push сразу меняет сайт для всех, поэтому push — только с согласия владельца и после проверки). Отзывы тестировщиков — GitHub Issues (шаблоны в `.github/ISSUE_TEMPLATE/`), Discussions и Telegram-бот @Print_calc_help_bot (проект `E:\Projects\print-calc-bot`, работает на домашнем сервере).

## Правила
- Чистые HTML/CSS/JS без сборки и без внешних библиотек: страница должна открываться двойным щелчком по `index.html` (поэтому данные Ozon — `.js`, а не `.json`).
- Формулы — только в `js/calc.js`. Любое изменение формулы проверять на эталоне: подставка cup-stand 4×5 (PETG 700 ₽/кг, тариф 5,83, 200 Вт, износ 50 ₽/ч, брак 2 %; боковины 100 г/2,3 ч и 100 г/2,33 ч, полка 65 г/1,42 ч ×4, кольцо 6 г/0,2 ч ×60) = **1 751 ₽**, как в `E:\Projects\cup-stand\cost\cost.xlsx`.
- Ставки Ozon — только из официальных таблиц (`tools/build_ozon_data.py`), сторонним сайтам с комиссиями не верить: они расходятся.
- Ничего не отправлять на сервер, никаких счётчиков: данные пользователя только в его `localStorage`.
- Сохранённые данные пользователей в `localStorage` (ключ `print-calc.v1`) не ломать: новые поля добирать умолчаниями (`fixProduct`, `load`).
- `data/ozon-raw/`, файлы `.3mf` и `.gcode` в git не кладём.
- Меняешь любой файл в `css/`, `js/` или `data/*.js` — обнови версию `?v=…` у всех подключений в `index.html` (одна общая метка, например `?v=ГГГГММДД` + буква). Иначе у посетителей браузер возьмёт старый файл из кэша и новая функция «не работает», пока не нажмут Ctrl+F5.

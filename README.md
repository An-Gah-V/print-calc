# Калькулятор 3D-печати

Считает себестоимость 3D-печати и цену продажи. Это одна страница: открывается в браузере, ничего не нужно устанавливать, данные никуда не отправляются.

## Что умеет
- **Себестоимость изделия из нескольких деталей:** пластик, электричество, износ принтера, работа, упаковка, запас на брак.
- **Читает файлы слайсера.** Перетащите `.3mf` (Bambu Studio, OrcaSlicer) или `.gcode` (Bambu, Orca, PrusaSlicer, Cura) — граммы и время каждого стола заполнятся сами.
- **Справочники:** свои принтеры (мощность, цена, ресурс) и материалы (цена и вес катушки).
- **Блок «Продажа» включается по желанию:**
  - «Наценка» — процент сверху и налог;
  - «Ozon» — комиссия и логистика по **официальным таблицам Ozon**: категория товара, схема FBO/FBS/rFBS, объём упаковки, кластер отправки;
  - «Другая площадка» — свои проценты и рубли.

  Результат: рекомендуемая цена, цена безубыточности и расклад «куда уходят деньги». Можно проверить и свою цену.
- **Мои изделия:** сохранение расчётов, копии, выгрузка в `.json` (резервная копия, перенос на другой компьютер) и в `.csv` для Excel.
- Светлая и тёмная тема, работает на телефоне.

## Как запустить
Откройте `index.html` двойным щелчком: он откроется в браузере. Интернет не нужен.

Для проверки через локальный сервер (как будет на сайте):
```
py -m http.server 8765 --bind 127.0.0.1
```
и откройте http://127.0.0.1:8765

## Как устроено
| Файл | Что внутри |
|---|---|
| `index.html` | разметка страницы |
| `css/style.css` | оформление, светлая и тёмная тема |
| `js/calc.js` | все формулы: себестоимость, цена продажи, комиссия и логистика Ozon |
| `js/slicer.js` | чтение `.3mf` (это zip-архив) и `.gcode` |
| `js/app.js` | интерфейс: таблицы, сохранение, поиск категории |
| `data/ozon-data.js` | ставки и тарифы Ozon (собирается скриптом, руками не править) |
| `tools/build_ozon_data.py` | превращает официальные xlsx Ozon в `data/ozon-data.js` |

## Как обновить тарифы Ozon
1. Откройте [Полный список комиссий и тарифов](https://seller-edu.ozon.ru/docs/commissions-tariffs/legal-information/full-actual-commissions.html).
2. Скачайте «Таблицу категорий и типов для расчёта вознаграждения» и «Таблицу с предельными тарифами» логистики FBO/FBS в `data/ozon-raw/` (папка не попадает в git).
3. Выполните:
   ```
   py -m pip install openpyxl
   py tools\build_ozon_data.py data\ozon-raw\<комиссии>.xlsx data\ozon-raw\<логистика>.xlsx "комиссии с ДД.ММ.ГГГГ, логистика с ДД.ММ.ГГГГ"
   ```
   Третий аргумент — подпись с датами, она показывается на странице.

Сейчас в калькуляторе: комиссии с 07.10.2026, логистика с 30.10.2026 (условия с 01.12.2026).

## Ограничения
- Это оценка, а не бухгалтерский расчёт. Точные удержания — в отчётах личного кабинета площадки.
- Для Ozon не учтены коэффициент снижения услуг Кр, обратная логистика при возвратах, платное размещение, реклама и акции.
- Логистика Ozon «в среднем по России» — простое среднее по всем направлениям из выбранного кластера, без учёта того, куда реально идут продажи.
